# Positional Value Tiers — When to Draft Each Position

_Quick reference for agents to know when each position should be drafted_

## League Context Modifiers

**4-pt passing TD** (not 6) = **QB is devalued significantly**
- In 6-pt passing TD leagues, elite QBs go Rounds 2-4
- In 4-pt passing TD leagues, **WAIT on QB until Round 8+** (unless elite tier falls)

**Full PPR** = **WR and pass-catching RBs elevated**
- WRs become equal value to RBs in early rounds
- Pass-catching RBs (Bijan, Achane, Gibbs) > rushing-only RBs

**14-team league** = **Scarcity matters more**
- Only 28 RBs drafted as starters (2 per team)
- Only 28 WRs drafted as starters (2 per team)
- TE/QB/D/K depth is THIN on waivers

## Round-by-Round Positional Priority

### **Round 1 (Pick 1):**
**Priority: Elite RB > Elite WR**

**Why RB over WR at 1.01:**
- RB scarcity: Only ~12 elite RBs, but ~20 elite WRs
- RB touches: Top RBs get 20+ touches/game, WRs get 8-10 targets/game
- RB floor: Less TD-dependent than WRs (rushing yards + receptions)

**Mock draft: Bijan Robinson (RB) at pick 1** ✅

**Exceptions:**
- If the consensus 1.01 RB has major red flags (injury, age 30+, committee backfield)
- If an elite WR is significantly safer (e.g., Bijan injured in camp → pivot to CeeDee Lamb)

---

### **Rounds 2-3 (Picks 28-29):**
**Priority: RB + WR (most balanced) OR WR + WR (high upside in PPR)**

**Options:**
1. **RB + WR** (safest, most common)
   - Locks RB2 + WR1
   - Mock draft: Javonte Williams (RB) + Nico Collins (WR) ✅
2. **WR + WR** (high-upside PPR strategy)
   - Leverages full PPR scoring
   - Requires drafting RB2 in Rounds 4-5 (riskier)
3. **RB + TE** (IF elite TE available)
   - Only if Travis Kelce or Sam LaPorta falls to 29
   - Solves TE scarcity early

**Avoid:**
- RB + RB (leaves WR room too thin in PPR)
- WR + TE (leaves RB room too thin — RB scarcity > TE scarcity)

**Mock draft strategy used:** RB + WR (balanced approach)

---

### **Rounds 4-5 (Picks 56-57):**
**Priority: Fill remaining starter holes (WR2, FLEX, or elite TE)**

**By pick 56, you should have:**
- 2 RBs OR 1 RB + 2 WRs
- 1-2 WRs OR 2 WRs + 0-1 RB

**Options at 56-57:**
1. **WR + WR** (if you went RB-RB-RB early)
2. **WR + TE** (if elite TE still available)
3. **RB + WR** (if you went WR-WR early)

**Mock draft: Rashee Rice (WR) + Evan Engram (TE)** ✅
- Filled WR2 + TE, leaving FLEX open for later

**Avoid drafting here:**
- QB (too early — 4-pt passing TDs devalue QB)
- D/ST (way too early — streaming exists)
- K (absolutely not)

## Positional Scarcity Tiers (14-team league)

**Tier 1 (Elite scarcity — draft early):**
- **RB:** Only ~8-10 true RB1s exist (Bijan, CMC, Breece, Gibbs, Taylor, Saquon, etc.)
- **WR (PPR):** ~15-20 true WR1s exist (more depth than RB)

**Tier 2 (Moderate scarcity — draft mid-rounds):**
- **TE:** Only 3-5 elite TEs (Kelce, Andrews, LaPorta, McBride), then massive drop-off
- **QB (in 4-pt passing TD):** 8-12 viable QB1s, but late-round QBs still startable

**Tier 3 (Low scarcity — wait until late rounds):**
- **D/ST:** Streaming by matchup >> drafting early (30+ viable D/STs throughout season)
- **K:** Completely random; zero edge from drafting early

## Agents: How to Use This File

When making a draft recommendation:

1. **Check what round we're in** → reference the "Round-by-Round Positional Priority" section
2. **Check roster composition** → ensure balance (2 RBs, 2 WRs minimum by Round 5)
3. **Cite specific tier/round rules:**
   - Example: "Per positional-value-tiers.md, Rounds 2-3 prioritize RB + WR. Recommend Javonte Williams (RB) at 28 and Nico Collins (WR) at 29."
4. **Flag reaches:**
   - Example: "User wants to draft Josh Allen at pick 28. Per positional-value-tiers.md, elite QBs should be drafted Rounds 4-6 in 4-pt passing TD leagues. This is a 2-3 round reach — recommend waiting."

This reduces tokens by having pre-written positional value logic instead of regenerating it every pick.
