## Scoring (key differences from click clack's full-PPR rules)

- **Receptions: 0.5 pt (half-PPR)** — NOT full PPR like click clack. Reception-heavy players are worth less here relatively; per-target volume still matters but raw catch totals inflate value less.
- Passing: 25 yds/pt (0.04/yd) + bonus 1 pt each at 350/400/450 yds. **Passing TD = 5 pts** (click clack is 4). INT = -2. Pick-six thrown = -3. 40+ yd pass TD = +1.
- Rushing/Receiving: 10 yds/pt (0.1/yd, same rate as click clack) + bonus 1 pt each at 150/200/225 yds. Rush/Rec TD = 6. 40+ yd rush/rec TD = +1.
- Fumbles lost: -2. Offensive fumble return TD: 6. 2-pt conversions: 2.
- Return yards count: 25 yds/pt, +2 bonus at 200 yds; return TDs = 6. (Relevant if a roster player returns kicks/punts.)
- **Kicker**: missed FG at ANY distance = -1 (harsh, unlike most leagues which only penalize short misses or not at all). PAT made = 1, missed = -1. FG total yards: 10 yds/pt.
- **D/ST — non-standard, different tiering than click clack**: Sack 1, INT 2, Fumble Rec 2, TD 6, Safety 3, Block Kick 3, Return yards 25/pt (+2 at 300), Return TD 6, XP returned 2, 4th-down stops 0.5, 3-and-outs forced 0.25. Points-allowed tiers: 0 pts=10, 1-6=7, 7-13=4, 14-20=1, 21-27=0, 28-34=-1, 35+=-4. (No total-yards-allowed component here, unlike click clack's D/ST rule — this is closer to standard points-allowed scoring, just with a generous shutout bonus.)

## Implication for pickups/rankings in THIS league

Don't reuse click clack's `state/research/*.md` strategy files uncritically — they're written for full-PPR + click clack's D/ST rule. In Death to Nottinghams:
- Discount pure high-volume-low-yardage pass-catchers slightly (half PPR softens their edge vs. click clack).
- QB is worth relatively more than in click clack (5-pt passing TD here vs. 4-pt there).
- D/ST streaming should target points-allowed matchups (shutout upside is heavily rewarded: 10 pts for a shutout), not yardage defense.
- Kicker accuracy matters more here since every miss costs a full point regardless of distance.
